# LactOS

A custom hobby Operating System built from scratch.

**Architecture:** x86 / bare-metal

## Development Environment

LactOS is actively developed, compiled, and emulated directly on an iOS device using:
- **iSH:** Terminal environment on iOS emulating Alpine Linux
- **Vim:** Linux text editor used on iSH
- **Subtext:** A text editor on iOS for quick edits
- **UTM SE:** For emulating and testing LactOS

## How To Use

1. Direct `.img` download:
  a. download `LactOS.img` from `/build/vdrive/`
  b. use `LactOS.img` as a floppy drive attached to a VM in your hypervisor of choice.

2. Clone the repository
  a. I'm going to assume if you choose to go this route you already know how to do this.

 ## Features:
 - A bootloader that works and boots you into 64 bit long mode
 - A basic VGA display / text console
 - Interrupt table
 - Basic keyboard driver
